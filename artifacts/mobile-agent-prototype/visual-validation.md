# 对话式知识 Agent 移动端原型走查

## 原型基线

- 对应页面：`docs/prototypes/grove-mobile-agent-prototype.html`
- 主验收视口：390 × 844；扩展视口：360 × 800、412 × 915。
- 全局令牌：沿用 `frontend/src/index.css` 的背景、正文、品牌绿、AI 候选紫、正式知识青、风险琥珀、错误红与边框色。
- 字体：系统字体栈；正文 14px，标题 16–23px，说明 10–12px。
- 应用壳：固定范围栏、对话内容区、自适应输入区与四栏底部导航；键盘态隐藏底部导航。
- 范围层级：只保留 Workspace 全部知识与项目两级，不在全局范围选择器中暴露目录节点。
- 图标：采用减笔后的原创「林间线稿」，轮廓偏圆润柔和；选中态仅改变图标与文字颜色，不使用底色或顶部短横线；另提供两组方向供比较。
- 关键状态：首次知识检索、复用工作集解释、Source 原文、新条件补检索、反例检索、跨范围重检索、冲突、知识不足、歧义澄清、可编辑草稿、完整差异、操作确认、执行完成、撤销、长任务、失败重试。

## 采用的页面结构

- 对话是默认首页；收集、待处理、知识作为低视觉重量的四栏骨架。
- Workspace 和项目显示为同一个知识 Agent 的当前范围；目录或 Entry 只作为可移除的临时上下文，不进入全局范围层级。
- 普通对话只承担目标表达；证据、差异、确认、执行和撤销使用结构化卡片或全屏审阅页。
- 首次回答后展示四个只读建议追问和一个远期操作入口；输入框通过阶段与意图路由进入同一组确定性分支，不再将任意第二轮固定路由到合并。
- 每个检索卡和回答卡都保留生成范围；Workspace 跨项目命中显示项目归属。范围切换后保留旧消息、插入明确分隔，并使旧工作集与旧修改方案失效。
- 已合并 Entry 保留来源和审计关系，不使用删除语义；冲突 Entry 默认不参与合并。

## 有意偏离

- 这是原生 App 产品形态的 HTML 交互原型，不是低于 1024px 的 Grove Web 业务页面，也不决定正式 App 技术栈。
- 移动端采用 40–48px 的主要触控控件和更紧凑的引用徽标，不复用桌面工作台的侧栏、表格和双栏确认布局。
- 长差异使用全屏审阅，范围与引用使用底部 Sheet，以适应 iOS 与 Android 小屏和安全区。

## 验收结果

- 360 × 800：文档与应用宽度均为 360px，无横向溢出；键盘顶部与输入区底部邻接且无重叠，发送只读追问后键盘保持展开。
- 390 × 844：连续追问、跨范围重检索与 Source Sheet 均无横向溢出；Source Sheet 的 Entry 总结、精确原文、上下文和来源名称可滚动查看。
- 412 × 915：只读回答进入修改建议、差异确认、执行回执与撤销的完整链路无横向溢出，底部导航完整可见。
- 键盘态：输入框聚焦后显示 390px 平台中性键盘示意，输入区移动至键盘上方，底部导航下移隐藏；字母、空格、标点、退格、发送和收起均可点击；发送后不主动失焦，只有收起键盘或点击输入区外部才恢复。
- 范围切换：选择器仅包含 Workspace 全部知识和 4 个项目，只有当前范围显示勾选，并通过 `role="radio"` + `aria-checked` 表达非颜色选中状态。对话中切换后插入范围分隔和工作集失效提示；下一问已实际重新检索。
- 连续提问：“为什么时长不一致”不增加全项目检索卡；“南方潮湿”显示潮湿、返潮与沿海环境补查；“相反经验”显示不适用、例外与失败经验检索，并对未找到的观点保留非绝对表达。
- 来源证据：「查看第二条的来源原文」直接打开证据 Sheet，清楚分开「对应正式 Entry」、「Entry 总结」与「Source 原文」，同时展示目录路径、Source 名称和必要上下文；当 Entry 有 2 个来源时显示「来源 1 / 2」并可逐条切换。
- 修改边界：从只读回答可继续进入现有合并流程；影响对象明确列出 1 条主 Entry 更新、2 条重复知识合并和 2 条冲突知识保留，摘要、列表、确认与回执数量一致。范围切换后旧澄清按钮、差异入口和确认执行入口立即失效。「全部知识」下即使完成只读重检索，也会先追问目标项目，不生成跨项目合并方案。
- 语义检查：Agent 综合回答使用「基于 6 条正式知识」等表达，不再将回答标记为「正式知识」；正式 Entry 详情与知识列表仍保留「正式知识」。AI 草稿使用「AI 建议 · 待确认」。
- 会话历史：首次与只读回答阶段显示「已回答」；用户选择合并策略并实际生成草稿后才更新为「已生成合并建议」。
- 焦点与弹层：Bottom Sheet 和全屏审阅层打开时背景进入 `inert`，焦点进入当前层并在层内循环；嵌套确认关闭后先返回全屏审阅触发按钮，退出全屏层后再返回对话触发按钮。
- 图标对比：三组原创 SVG 均可切换到 390px 实际尺寸预览；推荐组已用于主原型，图标放大至 24px，标签放大至 11.5px，底栏选中态无背景和短横线。
- 功能走查：首次问答、复用已读取 Entry 解释、Source 原文、新条件补检索、反例检索、范围切换后继续提问、只读回答进入修改、差异确认、执行回执、撤销、会话历史、键盘展开/收起与失败重试全部通过。
- 控制台：无 error 或 warning。

- 剩余差异：无未解释的视觉偏差。
