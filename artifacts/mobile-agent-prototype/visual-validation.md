# 对话式知识 Agent 移动端原型走查

## 原型基线

- 对应页面：`docs/prototypes/grove-mobile-agent-prototype.html`
- 主验收视口：390 × 844；扩展视口：360 × 800、412 × 915。
- 全局令牌：沿用 `frontend/src/index.css` 的背景、正文、品牌绿、AI 候选紫、正式知识青、风险琥珀、错误红与边框色。
- 字体：系统字体栈；正文 14px，标题 16–23px，说明 10–12px。
- 应用壳：固定范围栏、对话内容区、自适应输入区与四栏底部导航；键盘态隐藏底部导航。
- 范围层级：只保留 Workspace 全部知识与项目两级，不在全局范围选择器中暴露目录节点。
- 图标：采用减笔后的原创「林间线稿」，轮廓偏圆润柔和；选中态仅改变图标与文字颜色，不使用底色或顶部短横线；另提供两组方向供比较。
- 关键状态：知识检索、Entry/Source 引用、冲突、知识不足、歧义澄清、可编辑草稿、完整差异、操作确认、执行完成、撤销、长任务、失败重试。

## 采用的页面结构

- 对话是默认首页；收集、待处理、知识作为低视觉重量的四栏骨架。
- Workspace 和项目显示为同一个知识 Agent 的当前范围；目录或 Entry 只作为可移除的临时上下文，不进入全局范围层级。
- 普通对话只承担目标表达；证据、差异、确认、执行和撤销使用结构化卡片或全屏审阅页。
- 已合并 Entry 保留来源和审计关系，不使用删除语义；冲突 Entry 默认不参与合并。

## 有意偏离

- 这是原生 App 产品形态的 HTML 交互原型，不是低于 1024px 的 Grove Web 业务页面，也不决定正式 App 技术栈。
- 移动端采用 40–48px 的主要触控控件和更紧凑的引用徽标，不复用桌面工作台的侧栏、表格和双栏确认布局。
- 长差异使用全屏审阅，范围与引用使用底部 Sheet，以适应 iOS 与 Android 小屏和安全区。

## 验收结果

- 360 × 800：文档与应用宽度均为 360px，无横向溢出；输入区 52px，底部导航 62px。
- 390 × 844：差异页宽 390px，无横向溢出；固定确认按钮高度 44px。
- 412 × 915：文档宽 412px，无横向溢出；回执宽 380px，底部导航完整可见。
- 键盘态：输入框聚焦后显示 390px 平台中性键盘示意，输入区移动至键盘上方，底部导航下移隐藏；字母、空格、标点、退格、发送和收起均可点击；发送后不主动失焦，只有收起键盘或点击输入区外部才恢复。
- 范围切换：选择器仅包含 Workspace 全部知识和 4 个项目；对话中切换后插入范围分隔提示，知识页筛选标签只显示项目名。
- 图标对比：三组原创 SVG 均可切换到 390px 实际尺寸预览；推荐组已用于主原型，图标放大至 24px，标签放大至 11.5px，底栏选中态无背景和短横线。
- 功能走查：四栏切换、范围切换、引用详情、核心纵向场景、失败重试、知识搜索、Entry 详情与撤销全部通过。
- 控制台：无 error 或 warning。
