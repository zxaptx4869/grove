## 计算样式结果

1280×800 正式项目列表：

- 全局侧栏：216px；主顶栏：52px；
- 页面水平内边距：24px；页面顶部内边距：22px；
- 标题：22px / 30px / 650；
- 状态筛选：34px；项目行：66px；
- 项目图标：34px；状态标识：约 22px；进入项目按钮：34px；
- 页面横向溢出：0px。

1023×800 只渲染“请在电脑端打开 Grove”，没有应用侧栏和项目状态筛选。1024×800 渲染完整工作台，侧栏按窄桌面规则为 184px，横向溢出为 0px。

## 有意偏离

- 顶栏不显示“搜索”和“快速采集”，因为本轮没有对应业务能力；保留了 52px 壳层与边界。
- 侧栏“收集箱”和“搜索”保持不可用，不展示原型静态数量，也不提供假路由。
- 项目行只显示真实目标与背景、目录节点数；不伪造正式知识、候选或更新时间。
- 项目图标使用统一 Lucide 图标，不根据项目名称猜测语义图标。
- “进入项目”后保留更多菜单，承载已实现的生命周期变更与删除；删除仍需二次确认。
- 正式页面不复制原型文档的切换栏、外层圆角窗口、投影和静态项目数据。

## 状态复核

- loading 使用三行 66px 稳定骨架；empty 提供当前筛选说明与相关动作；error 提供邻近错误和重试；
- 暂停筛选空态已在浏览器确认；收集箱和搜索为 `aria-disabled`；
- 更多菜单、删除二次确认、创建按钮 disabled 与键盘可达状态保留；
- 浏览器控制台无 warning 或 error。
