## 计算样式

浏览器在 1280px 下实测：

- body：14px / 21px / 430；系统字体栈；无 body 级 `-webkit-font-smoothing: antialiased`。
- 页面标题：22px / 30px / 650。
- 当前导航：14px / 21px / 600。
- 页面说明、最近项目、状态筛选：430。
- 项目名称：14px / 21px / 500；项目说明：12px / 18px / 430。

## 对照结论

- 三档视口下字体层级、颜色、布局和间距稳定，无横向滚动、遮挡或文字溢出。
- 常规中文正文从 400 调整到原型基线 430，并恢复系统默认字体平滑，字面比上一版更深、更稳。
- 筛选项不再无差别使用 600；项目名称从 650 回落到原型的中等层级，标题、当前导航和正文之间的层级更清楚。

## 有意偏离

- 原型中的收集箱计数、账户主导航、全局搜索和快速采集未进入当前产品基础体验规格，不补静态入口。
- 原型项目行中的正式知识数、候选数和更新时间没有真实 API 字段，正式页面只显示目标与背景和目录节点数。
- 正式前端使用真实账号、Workspace 和项目数据，因此数量与原型静态数据不同。
