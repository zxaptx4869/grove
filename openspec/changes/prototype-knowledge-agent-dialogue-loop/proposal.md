## Why

当前知识 Agent 的统计追问已有改善，但真实复合问答仍出现证据未利用、未完成查询被表达为零条、以及任务与工作集衔接失败。需要用范围有限的真实对照确认“统一对话与工具循环”是否值得正式接入，避免继续大规模修改后才验证体验。

## What Changes

- 增加仅命令行使用的实验入口，复用现有 Pydantic AI 和真实只读领域工具，让同一 Agent 接续用户原话、历史和工具结果，选择下一步动作；不经过现有前置分类、完整执行图与独立覆盖补答链路。
- 实验允许混合文字、真实统计和列表引用；程序继续负责身份、范围、对象和来源校验，并明确区分空结果、部分结果与未执行。
- 使用现有 demo 数据的一致快照和隔离的临时数据库分别运行旧流程、新循环；先做无模型调用的边界检查，再执行三组固定多轮对照，生成本地审阅报告。
- 固定首批消息数、模型与工具预算、停止条件和升级判据；不自动追加付费批次，不将有限样本成功率外推为整体质量。
- 在保留第一版报告与结论的前提下实施原型第二版：用确定性的结构化历史摘要替代历史大段正文，保留用户原话、已展示回答、查询条件、状态、完整性、必要统计、列表句柄与准确顺序；需要正文或来源时按当前轮权限重新读取。
- 第二版在实验适配层拆分精确总数与分组统计工具，明确记录类型筛选默认为全部正式记录，并在每次模型请求前估算包含本轮新增工具材料的输入长度、预留预算内收尾请求；不新增分类、摘要或覆盖检查模型。
- 第二版加强无模型测试、全链路彩排和评分，并准备原三组对照及少量未写入提示词的表达变体；本阶段不启动真实评测，待提交冻结模型、快照、消息数和请求预算后再由用户确认。

第一版实现与真实评测已经完成，报告保留在 `backend/data/knowledge-agent-evals/dialogue-loop/20260907-141328/`，结论仍为不建议正式接入。用户已批准第二版规划修订、实验代码和无模型验证，但尚未批准第二版真实评测。范围仍仅限实验，不包括切换正式入口。

## Capabilities

### New Capabilities

- `knowledge-agent-dialogue-loop-experiment`：隔离的统一对话循环实验、可信工具和混合结果合同、有界真实对照及可审阅报告。

### Modified Capabilities

无。实验不改变现有 App/API/Worker 的路由、回答协议或任务工作集规格，不撤销已有只读工具的权限、发现集合与本轮 Evidence 规则。

## Impact

- 修改既有 `backend/evals/dialogue_loop/` 实验包、对应后端测试和 `backend/evals/README.md`。复用 `app/services/knowledge_agent/` 的领域工具、`RunToolContext`、Provider 配置与旧流程入口；共享业务代码只读复用，缺陷阻断复用时先记录影响，不借实验顺手修复正式链路。
- 无公开端点、数据库迁移、依赖框架替换或 Web/原生界面改动。实验会写入临时副本的 Run、Evidence 和审计，以及本地报告，不写真实业务库。
- 分支 `codex/prototype-knowledge-agent-dialogue-loop` 从 `codex/fix-knowledge-agent-multiturn-context` 的 `5f867c0` 创建。基础分支仍有待验收事项；本实验不完成或归档基础 change，也不掩盖其已知失败。
- 若实验支持继续，回到基础开发分支明确正式改造范围，选择性复用有效代码；不直接将实验分支整体合入主分支。
- 非目标：App 接入与视觉验收、完整生产恢复机制、旧对话迁移、深度调查重写、外部搜索、多 Agent、正式知识写操作和模型选型比较。

必要范围和验收合同完整写在本 change 中，不依赖未纳入 Git 的 discussions 文档。
