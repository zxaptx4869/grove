## Why

思维导图适合「按空间位置回忆」，但用户进入项目后缺少一眼看清「整个项目的目录结构、知识密度与空白区域」的全局视图。旭日图正好补上这一层；同时旭日图与思维导图各自独立入口会让导航变复杂，合并为单一「知识全景」视图、顶部切换，既保留两种模式的互补价值，又降低入口成本。

## What Changes

- 新增项目级「知识全景」视图（`view=overview`，无壳沉浸式），**默认展示旭日图**；顶部提供「旭日图 | 思维导图」切换。
- 思维导图模式复用现有 MindMapView 能力，从独立 `view=mindmap` 并入知识全景（**BREAKING**：移除 `view=mindmap` 入口，改由 `view=overview&mode=mindmap` 承载）。
- 旭日图模式：扇区按深度单色着色、宽度 = 知识量（沿用「直接 / 后代 / 合计」口径）；hover 高亮祖先路径并显示计数；点击扇区图内钻取，面包屑返回；标签按弧长缩写、hover 补名。
- 缩放：采用 SVG viewBox 手写缩放与平移（滚轮以光标为中心 + 按钮 + 适应窗口），**不引入第三方依赖**。
- 跨模式联动：旭日图选中节点后提供「在思维导图中查看」→ 切换模式并聚焦该节点；思维导图模式提供「查看全景」返回。
- 右侧大纲联动（沿用原型）：目录大纲点击联动旭日图，直接知识列表配合 EntryPopover 悬浮详情（hover 预览 + 点击固定）。
- 入口收敛：知识空间页头与项目首页的「思维导图」入口替换为「知识全景」，不保留双入口。

## Capabilities

### New Capabilities
- `knowledge-overview`: 知识全景视图——旭日图全局浏览（钻取、缩放、计数口径、标签策略）、旭日图/思维导图模式切换、跨模式联动与大纲联动。

### Modified Capabilities
- `directory-mind-map`: 思维导图入口与沉浸壳行为变更——由独立 `view=mindmap` 并入知识全景 `view=overview&mode=mindmap`，并提供「查看全景」返回。
- `node-tree`: 知识空间工作台入口变更——页头由「思维导图」入口改为「知识全景」入口（含旭日图与思维导图模式）。

## Impact

- 前端：`ProjectPage` 增加 `view=overview` 分支与「知识全景」入口（替换思维导图入口）；`AppShell` 沉浸式条件覆盖 overview；新增旭日图与知识全景视图组件，恢复/重构原型旭日图实现；`MindMapView` 调整为知识全景内的模式；复用 `EntryPopover`；URL 增加 `mode` 参数。
- 后端：无新增端点，复用 `tree`、`node entries`、`project entries` 接口。
- 依赖：无新增。
- 文档：《功能优先级与Change顺序》已补 P1 项与 change 19；《目录与知识空间》思维导图小节将同步为并入知识全景的表述。

## Non-Goals

- 不在旭日图/知识全景中提供目录或知识的编辑、移动、删除与拖拽。
- 不做项目首页全景卡（该方向已否决）。
- 不做旭日图与思维导图同屏并排布局（同一视图内切换，不同屏展示）。
- 旭日图不承担全文阅读：悬浮窗仅做预览与来源查看。
- 不引入图/脑图第三方依赖（缩放与布局均手写）。
- 不实现手机 Web 业务界面；桌面 ≥1024px。
