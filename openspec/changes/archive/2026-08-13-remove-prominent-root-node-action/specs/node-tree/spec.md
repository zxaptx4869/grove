## MODIFIED Requirements

### Requirement: 知识空间目录工作台
知识空间 SHALL 作为项目上下文中的独立视图，使用真实目录树 API 和 250px 树栏加剩余知识内容区的桌面工作台结构。树栏 MUST 承载根节点创建、节点选择和节点上下文操作；非空目录的根节点创建动作 MUST 仅在树栏标题区提供，不得在页头重复呈现为主按钮。非空目录首次加载 SHALL 默认选择第一个根节点，内容区 MUST 展示选中节点的路径、名称、可选说明、编辑入口和“暂无正式知识”的真实空态。创建、编辑、移动、排序和删除 SHALL 继续使用真实接口，删除保留二次确认；AI 共创入口 SHALL 明确 Directory Agent 尚未实现。系统在没有 Entry 能力时 MUST 不展示知识卡片、列表、来源、更新时间、直接/子树知识数或其他静态假数据。

#### Scenario: 非空目录工作台
- **WHEN** 用户打开包含目录节点的知识空间
- **THEN** 页面显示 250px 目录树栏、真实节点数量、树栏标题区的根节点创建动作和剩余内容区，不在页头显示重复的“根节点”主按钮，并默认选中第一个根节点显示其真实路径、名称、说明、编辑动作和无正式知识空态

#### Scenario: 切换目录范围
- **WHEN** 用户选择另一个目录节点
- **THEN** 目录树选中态和内容区的路径、名称、说明与知识空态同步更新，不显示其他节点或静态知识内容

#### Scenario: 空目录工作台
- **WHEN** 用户打开空目录项目的知识空间
- **THEN** 页面保持稳定的两栏工作台边界，并在内容区提供“手动创建第一个节点”和“与 AI 共创目录”两个平等入口

#### Scenario: 目录操作状态完整
- **WHEN** 用户创建、编辑、移动、排序或删除目录节点
- **THEN** 相应动作具有 disabled、错误、成功反馈和必要的破坏性确认，操作完成后刷新真实目录树，不显示静态节点或静态知识

#### Scenario: AI 共创能力未实现
- **WHEN** 用户选择“与 AI 共创目录”
- **THEN** 页面明确说明入口已预留但 Directory Agent 尚未实现，不生成或应用伪目录草稿

#### Scenario: 未实现知识模式不冒充可用
- **WHEN** Entry、知识列表或思维导图尚无当前 OpenSpec 实现
- **THEN** 页面不显示可操作的卡片/列表切换、思维导图入口、知识计数、来源数或静态正式知识
