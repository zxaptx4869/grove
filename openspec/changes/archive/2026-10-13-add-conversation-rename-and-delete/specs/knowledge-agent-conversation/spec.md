## ADDED Requirements

### Requirement: 对话重命名与用户命名优先
系统 MUST 提供对话重命名接口，允许对话归属用户把标题改为去除首尾空白后的非空字符串，长度上限 255 字符；空白标题、只有空白字符或超长标题 MUST 被拒绝且不改变原标题。被用户命名后，系统 MUST NOT 再用首条消息自动改写标题；自动命名 MUST 只在对话从未被用户命名且标题仍为默认值时发生，并沿用首条消息前 30 字符、超出部分以省略号结尾的既有口径。重命名 MUST 只更新标题与更新时间，MUST NOT 改变最近活动时间，MUST NOT 影响范围、消息、Run 与工作集；活动 Run 期间重命名 MUST 照常可用。

#### Scenario: 重命名空闲对话
- **WHEN** 用户对自己拥有的对话提交合法新标题
- **THEN** 系统持久化新标题并返回包含新标题的对话摘要，最近活动时间保持不变

#### Scenario: 已命名对话不再被首条消息覆盖
- **WHEN** 用户先把对话重命名为自定义标题，随后发送第一条消息
- **THEN** 系统保留用户标题，不写入自动标题

#### Scenario: 命名回默认标题仍受保护
- **WHEN** 用户把对话标题改回默认标题，随后发送第一条消息
- **THEN** 系统仍视为用户已命名，不写入自动标题

#### Scenario: 未命名对话自动命名
- **WHEN** 从未被用户命名的对话首次提交问题且标题仍为默认值
- **THEN** 系统用首条消息前 30 字符命名，超出部分以省略号结尾

#### Scenario: 非法标题被拒绝
- **WHEN** 用户提交空白标题、只有空白字符的标题或超过 255 字符的标题
- **THEN** 系统拒绝该请求、返回明确的校验错误且不改变原标题

#### Scenario: 活动 Run 期间重命名
- **WHEN** 对话存在 `waiting` 或 `processing` Run 且用户重命名该对话
- **THEN** 系统照常保存新标题，不打断或取消该 Run

#### Scenario: 重命名越权对话
- **WHEN** 用户重命名其他 Workspace 或其他用户的对话
- **THEN** 系统返回 404 且不改变任何标题

### Requirement: 对话软删与读路径隐藏
系统 MUST 以软删方式删除对话：记录删除时间并保留对话及其消息、Run、工作集版本、候选草稿、修订草稿与调查记录，MUST NOT 物理删除受管记录，MUST NOT 依赖数据库级联来保证清理。删除后该对话 MUST 在列表、详情、消息、范围切换、Run、草稿、调查与可观测性等全部读写路径上按不存在处理（404），对话列表 MUST NOT 再返回它，按 id 直读其 Run 与草稿同样 MUST 返回 404。删除 MUST 校验归属，非本 Workspace 或其他用户的对话一律 404；对话存在 `waiting` 或 `processing` Run 时删除 MUST 冲突且不改变对话；重复删除同一对话 MUST 幂等成功。

#### Scenario: 删除空闲对话
- **WHEN** 用户删除自己没有活动 Run 的对话
- **THEN** 系统记录删除时间并返回成功，该对话不再出现在对话列表

#### Scenario: 删除后读取对话
- **WHEN** 客户端用已删除对话的 id 读取对话、提交消息或切换范围
- **THEN** 系统返回 404 且不返回消息、Run 或工作集数据

#### Scenario: 删除后直读关联 Run 与草稿
- **WHEN** 客户端用 id 直接读取属于已删除对话的 Run、可观测性记录或候选草稿
- **THEN** 系统返回 404 且不暴露这些记录

#### Scenario: 活动 Run 期间删除
- **WHEN** 对话存在 `waiting` 或 `processing` Run 且用户请求删除
- **THEN** 系统返回冲突响应，对话与 Run 保持原状

#### Scenario: 重复删除
- **WHEN** 用户对同一对话重复提交删除请求
- **THEN** 系统幂等返回成功，不报错、不影响其他对话

#### Scenario: 删除越权对话
- **WHEN** 用户删除其他 Workspace 或其他用户的对话
- **THEN** 系统返回 404 且不改变该对话

#### Scenario: 删除不影响正式知识
- **WHEN** 用户删除一个曾确认过候选草稿的对话
- **THEN** 已确认的 Candidate 与 Entry 保持可用，并仍可追溯到其来源材料
