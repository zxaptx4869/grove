## MODIFIED Requirements

### Requirement: 修改目录

系统 MUST 支持在批量视图为选中候选选择一个当前项目内的统一目录节点；用户确认后 MUST 将该节点持久化到每条选中候选，列表刷新并清空勾选；批量确认时 MUST 优先使用该持久化节点，未设置时回退到候选自身推荐。

#### Scenario: 确认后立即生效

- **WHEN** 用户为选中的候选选择统一目录节点并点击确认
- **THEN** 所选候选持久化该节点，批量列表刷新、勾选清空、操作按钮回到置灰

#### Scenario: 统一目录覆盖

- **WHEN** 用户为选中的候选设置统一目录节点并批量确认
- **THEN** 这些候选归档到统一节点，而非各自推荐节点

#### Scenario: 批量采纳使用持久化目录

- **WHEN** 用户对已设置统一目录的候选执行批量采纳
- **THEN** 这些候选归档到持久化的统一节点，而非各自推荐节点

#### Scenario: 未设置统一目录使用推荐

- **WHEN** 候选没有用户确认的目录节点
- **THEN** 批量采纳继续使用候选自身推荐节点
