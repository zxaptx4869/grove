## MODIFIED Requirements

### Requirement: 项目上下文中的全局入口

应用壳侧栏 MUST 始终在顶部固定展示全局一级菜单（项目 / 收集箱 / 搜索），进入项目后一级菜单保持不变，项目上下文（项目名与项目内导航）置于其下；项目内导航 MUST 提供项目首页、知识空间与确认台入口，且 MUST NOT 提供「采集与来源」与「AI 阅读」入口；统一知识问答由全局「知识 Agent」入口承担；来源历史页 `/sources` MUST 可访问但 MUST NOT 出现在侧栏菜单中；`/projects/:id?view=sources` 旧路由 MUST 保留兼容。

#### Scenario: 一级菜单固定顶部
- **WHEN** 用户在项目列表或任意项目视图切换
- **THEN** 侧栏顶部的「项目 / 收集箱 / 搜索」保持位置不变，只有项目上下文区块随进入项目而变化

#### Scenario: 项目内不出现来源菜单
- **WHEN** 用户进入项目查看侧栏
- **THEN** 项目导航不包含「采集与来源」入口

#### Scenario: 项目内不出现 AI 阅读入口
- **WHEN** 用户进入项目查看侧栏
- **THEN** 项目导航不包含「AI 阅读」入口，统一知识问答只经全局「知识 Agent」入口进入

#### Scenario: 旧 AI 阅读路由不再保留视图
- **WHEN** 用户直接访问 `/projects/:id?view=ai-read`
- **THEN** 页面重定向到该项目首页，不再渲染旧阅读视图

#### Scenario: 来源历史页不进菜单
- **WHEN** 用户通过收集箱「查看全部来源」或项目首页来源入口访问 `/sources`
- **THEN** 全屏历史页正常渲染，且侧栏菜单不显示对应一级入口

#### Scenario: 旧来源路由兼容
- **WHEN** 用户直接访问 `/projects/:id?view=sources`
- **THEN** 仍可打开来源视图，不做 404

### Requirement: 项目侧栏项目切换下拉

项目上下文侧栏 MUST 在项目名旁提供项目切换下拉；下拉 MUST 列出全部非归档项目并按状态分组（进行中 / 暂停 / 已完成），当前项目 MUST 在其所属分组中置顶并显示选中态；选择其他项目 MUST 跳转到该项目并保留当前视图类型（项目首页 / 知识空间 / 确认台）；当前项目为已归档时 MUST 在下拉顶部单列显示以保留位置感；下拉 MUST 提供「全部项目」入口进入 `/projects`；非项目页面 MUST NOT 显示该下拉，保持「最近项目」区块。

项目状态 MUST 以「文字 + 边框 + 浅底色」小标签展示：进行中为成功色、暂停为警告色、已完成为确认色、已归档为弱化色；切换按钮 MUST 为两行布局（项目名 + 状态标签），与下方项目导航间距 MUST 不大于 8px；下拉项目项 MUST NOT 展示状态图标，当前项目 MUST 显示选中勾。

#### Scenario: 状态图标化展示

- **WHEN** 用户进入项目工作台查看侧栏
- **THEN** 切换按钮显示「项目名 + 状态文字标签」，标签带边框与浅底色并使用语义色区分，不再使用纯图标

#### Scenario: 下拉项目项带状态图标

- **WHEN** 用户展开项目切换下拉
- **THEN** 每个项目项仅显示选中勾与项目名，不再显示状态图标，分组标题以文字表达状态

#### Scenario: 切换区域紧凑

- **WHEN** 用户查看项目工作台侧栏
- **THEN** 切换按钮与项目导航之间间距不大于 8px，无多余垂直留白

#### Scenario: 打开项目切换下拉

- **WHEN** 用户进入任意项目工作台并点击项目名旁的切换按钮
- **THEN** 下拉列出全部非归档项目，按「进行中 / 暂停 / 已完成」分组，当前项目在所属分组中置顶并显示选中态，底部提供「全部项目」入口

#### Scenario: 切换项目保留视图

- **WHEN** 用户在 A 项目的「知识空间」（或确认台）从下拉选择 B 项目
- **THEN** URL 切换到 B 项目并保持相同视图类型，页面与侧栏激活态同步

#### Scenario: 查看已归档项目

- **WHEN** 当前项目状态为已归档
- **THEN** 下拉顶部单列显示当前项目并标记选中态，其他已归档项目不进入列表

#### Scenario: 非项目页保持最近项目

- **WHEN** 用户在项目列表、收集箱或搜索页
- **THEN** 侧栏不显示项目切换下拉，仍显示「最近项目」区块
