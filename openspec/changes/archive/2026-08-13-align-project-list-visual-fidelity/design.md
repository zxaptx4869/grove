## Context

项目列表已经接入真实后端并具备四种生命周期筛选、创建、状态变更和删除，但视觉实现只复用了原型的大致信息层级。当前 `AppShell` 在 1680px 外框内又对主内容使用 1240px 居中限宽，`ProjectsPage` 再使用 1040px 居中限宽；两层约束使内容起点和右侧主操作明显偏离原型。应用主区缺少原型的 52px 顶栏，侧栏与主区表面颜色相反，主题令牌、字号阶梯、筛选样式和项目行动作也采用了近似参数。

本轮只调整项目列表直接可见的全局壳和页面表现。产品行为继续以 OpenSpec 主规格与真实 API 为准，`docs/prototypes/grove-product-prototype.html` 的 `projects` 页面只用于视觉、信息层级和交互形态参考。

## Goals / Non-Goals

**Goals:**

- 在 1280px、1440px、1600px 下对齐原型的侧栏宽度、52px 横向层级、页面内边距、标题区、筛选和项目行几何。
- 将基础表面色、文字色、品牌色、边框色、字体栈、字号、行高与圆角校准到原型基线，并继续通过 Tailwind 语义令牌使用。
- 保留真实项目状态、目录节点数、可选目标与背景以及现有 loading、empty、error、disabled 和删除确认行为。
- 使用截图和浏览器计算样式复核，不再仅以 DOM 存在或主观结构相似作为视觉完成标准。

**Non-Goals:**

- 不实现收集箱、搜索、快速采集、账户页、正式知识数、候选数或更新时间。
- 不修改项目工作台和认证页的专属页面结构，不重新设计共享组件库。
- 不修改后端接口、Workspace 权限、数据库模型或迁移。
- 不复制原型外层展示窗口、静态数据、内联样式或模拟脚本。

## Decisions

### 1. 保留、重写与删除边界

- **保留**：`useQueries` 的真实四状态项目查询；TanStack Query 刷新策略；创建项目、状态变更、删除项目 mutation；真实 `description` 与 `node_count` 展示；创建和删除对话框；最近项目真实数据；账户菜单与退出确认；1024px 端侧阻断。
- **重写**：`AppShell` 的桌面网格、品牌栏、全局导航密度、主顶栏和内容容器；`ProjectsPage` 的标题区、筛选栏、项目行与动作区 Tailwind 结构；基础视觉令牌。
- **删除**：应用外层 1680px 居中窗口、主内容 1240px 居中限宽、项目页 1040px 居中限宽、黑底激活筛选、用纯箭头代替“进入项目”的主动作。
- **不删除**：更多菜单继续承载生命周期和删除等次级操作，因为这些是真实且在本轮范围内的能力；它位于明确的“进入项目”按钮之后，不替代主动作。

选择局部重写而非推倒页面，是因为数据查询、权限边界和 mutation 已符合产品规格，偏差集中在表现层几何和令牌。也不抽取新的页面框架组件，避免为尚未逐页对齐的工作台提前建立复杂抽象。

### 2. 采用原型的页面结构

正式页面采用以下可见结构：

1. 216px 白色全局侧栏；品牌栏固定 52px，底部有分隔线。
2. 主区为纵向布局；顶部保留 52px 白色表面和底部分隔线，建立与品牌栏一致的横向基准。
3. 顶栏以下主内容使用页面底色，项目页以 `22px 24px 30px` 内边距铺满可用宽度，不再居中限宽。
4. 标题与主操作位于同一行，标题 22px/650，说明 14px；标题区下方 20px 进入状态筛选。
5. 状态筛选使用原型的紧凑横排：34px 左右高度、透明非激活态、白色激活态与轻阴影，下方列表从一条边框线开始。
6. 项目行最小高度 66px，使用 34px 图标容器、14px 项目名、12px 次要信息、22px 状态标识和 34px“进入项目”描边按钮。

在 1024px 至 1120px 的窄桌面范围继续将侧栏收窄为 184px，保证主区操作不溢出；1280px 及以上使用 216px。这是原型已有媒体规则。

### 3. 主题令牌以原型当前明暗基线为准

使用语义变量承接原型参数，不在页面组件中散落十六进制业务颜色：

- 页面底色 `#f7f8f7`，表面 `#ffffff`，柔和表面 `#f1f4f2`；
- 主文字 `#17201c`，次文字 `#66716b`，边框 `#dde3df`；
- 品牌绿 `#236748`，品牌柔和底 `#e8f3ed`；
- 全局字体为系统字体、PingFang SC、Microsoft YaHei，根字号 14px、行高 1.5、字距 0。

Tailwind 自定义字号阶梯会把 `display` 校准为 22px、页面正文校准为 14px，并保持 `caption` 12px。共享令牌变化可能自然影响认证页和工作台的颜色与字体，这是建立一致视觉基线的预期结果；不在本轮逐页修正它们的专属间距。

### 4. 原型中的有意偏离

- 顶栏保留 52px 结构与分隔线，但不显示搜索和快速采集按钮，因为对应能力尚未实现；空顶栏只承担稳定壳层几何，不提供伪入口。
- 侧栏的收集箱和搜索继续显示为明确 disabled 的未来全局导航，以满足现有 `product-shell` 规格；不显示原型静态数量，也不添加路由。
- 项目次要信息只显示真实的目标与背景和目录节点数；不显示正式知识、待确认候选或更新时间，避免静态假数据。
- 项目使用统一的 `FolderKanban` Lucide 图标，不根据项目名猜测 Home、Heart 等语义图标。
- 继续保留更多菜单，用于真实生命周期变更和删除；原型静态截图没有展示这些状态管理入口。
- 正式应用不复制原型的外层圆角窗口、边框和投影，那是文档中的演示容器而非产品页面。

### 5. 前后端接口与数据迁移

前端继续调用现有认证、按状态列项目、创建项目、更新项目状态和删除项目接口。请求参数、响应模型、缓存键和 Workspace 归属校验均不改变。

本轮无数据库字段、枚举或索引变化，因此不创建 Alembic 迁移，也不执行数据回填。回滚只需恢复前端样式和结构代码，不影响任何持久化数据。

### 6. 验收方式

- 自动化：更新项目列表测试以覆盖可见“进入项目”链接和真实字段；运行前端测试、lint、build 与 OpenSpec 严格校验。
- 浏览器：在 1280×800、1440×900、1600×900 生成正式页面截图并记录路径；使用相同宽度的原型页面或用户提供的原型截图对照。
- 对照维度：侧栏/顶栏尺寸、页面内容起点、主操作右边界、背景层级、标题字号、筛选高度和选中态、行高、图标/徽标/按钮尺寸。
- 端侧边界：1023px 只显示电脑访问提示且不加载工作台；1024px 显示完整桌面壳。

## Risks / Trade-offs

- [共享主题令牌会影响其他页面的基础色与字体] → 只调整原型已明确的全局基线，截图检查项目列表与项目工作台是否出现明显回归，其他页面专属布局留给后续逐页 change。
- [空顶栏与原型有按钮时视觉重量不同] → 保留准确高度、表面色和边界，明确记录这是业务范围导致的有意偏离，不用 disabled 假按钮填充。
- [不同操作系统中文字体渲染存在细微差异] → 使用原型相同系统字体栈和明确字号/行高，以 macOS 当前验收环境为截图基准。
- [真实数据长度不同于原型静态数据] → 使用稳定尺寸、截断与弹性布局验收，不能为了截图替换为静态数据。
- [项目更多菜单使行尾动作比原型多] → 保持直接进入按钮为第一主动作，更多菜单使用 34px 图标按钮并减少视觉权重。
