## Why

上一轮将侧栏项目状态改为纯图标展示，用户反馈图标不易看懂；状态应保留文字，并以「边框 + 浅底色」的小标签样式呈现，与系统其他位置的 Badge 一致，兼顾可读性与区分度。

## What Changes

- 撤销侧栏状态纯图标方案：切换按钮恢复两行布局（项目名 + 状态标签），状态以文字小标签展示，带边框与浅底色、语义色区分（进行中 / 暂停 / 已完成 / 已归档）。
- 下拉项目项不再显示状态图标，恢复「选中勾 + 项目名」简洁样式；已归档单列项保留「已归档」文字。
- 保留上一轮间距收紧：切换按钮与项目导航间距保持 8px。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `product-shell`: 项目侧栏项目状态的展示方式由纯图标改为「文字 + 边框 + 浅底色」小标签。

## Impact

- 前端：仅修改 `frontend/src/components/layout/AppShell.tsx`（移除状态图标映射，新增状态标签映射与 Badge 展示）及对应测试；无后端、API、数据库变化。
- 测试：更新 AppShell 测试断言状态标签文字；`npm run lint`、`npm run test`、`npm run build`。

## Non-Goals

- 不改变下拉的内容、分组、切换保留视图等既有行为。
- 不调整侧栏宽度、品牌栏、顶栏结构。
- 不引入新的状态色或图标令牌以外的自定义颜色。
