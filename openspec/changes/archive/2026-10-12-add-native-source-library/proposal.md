## Why

原生「收集」栏目在 `add-native-source-capture` 之后已经能采集，但采完就断了：入口页没有列表，用户看不到材料是否真的入库、处理到哪一步、为什么失败，也无法改归属或删除。真机与代码双向确认还有一个更硬的问题：`POST /api/sources/{id}/process` 若没成功，来源会一直停在等待处理且**没有任务行**，处理 Worker 只轮询已存在的任务行，这条来源永远不会被处理，而列表里也看不出异常。

本 change 在已归档的采集链路上补齐**来源列表、只读详情、改归属、删除与前台轮询**，并顺带补上移动端需要的「等待处理未启动」识别与重试入口。

## What Changes

- 收集入口页在三个采集入口下方新增「最近收集」列表（最近 20 条、创建时间倒序），与筛选「全部 / 未归属」同页；下拉刷新重新查询，不做分页、搜索与状态筛选，也不做独立「全部来源」页。
- 列表行显示类型、标题、附件摘要、创建时间、状态徽标、归属标签与 `done` 副状态；失败来源显示失败原因与「重试」，处理中/已完成/已处理完成不提供重复触发。补充说明不进列表。
- 新增只读来源详情：元信息（类型 / 创建时间 / 项目归属 / 补充说明）、原始材料（图片网格与放大查看、文字正文）、OCR 文本、AI 候选（只读，含目录建议与理由）。详情底部固定操作条提供「改归属」与「删除」；不提供候选的确认 / 拒绝 / 写入 / 归档。
- 改归属：打开前用 `project_locked` 与处理状态预判并说明原因，服务端 409 作为兜底；成功后按服务端重新路由的耗时给出「更换项目中」pending 态与可读的进行中说明。
- 删除：处理中与已被正式知识引用两类由服务端 409 阻止并原样展示文案；有 pending 候选时二次确认并说明「将一并移除这些候选」；成功后回到列表并刷新。
- 前台轮询：复用 `useAppStateActive`，仅前台且列表存在等待处理 / 处理中的条目时轮询，全部结束即停止；进后台停止请求，回前台立即查询一次再决定是否继续。间隔写入 `design.md`。
- 后端在 `SourceOut` 新增 `has_processing_task`，复用来源列表已有的批量处理任务查询，用于区分「有处理任务 / 无处理任务」；移动端据此对「等待处理且没有任务」的来源显示「处理未启动」并提供「重试处理」。不使用时间阈值启发式。
- 错误处理：后端 4xx 文案原样透传；网络失败在列表与详情分别给出可重试提示，不静默失败。

## Capabilities

### New Capabilities

- `native-source-library`：最近收集列表与筛选、列表条目与副状态口径、处理失败与未启动的重试、下拉刷新与列表状态、只读来源详情、改归属（预判与 409 兜底）、删除（三类阻止与 pending 二次确认）、前台轮询。

### Modified Capabilities

- `native-source-capture`：入口页从「MUST NOT 提供最近收集列表」改为在采集入口之外同时承载「最近收集」列表，列表行为由 `native-source-library` 规定。
- `source-management`：`SourceOut` 的响应状态字段新增 `has_processing_task`，与 `failure_reason` / `retry_count` 同口径返回。

## Impact

- `mobile/src/sources/`：新增来源库模块（API 封装、状态派生、列表与筛选、只读详情、改归属、删除、前台轮询）与对应单测；`mobile/src/capture/components/CaptureScreen.tsx` 的入口页接入列表并托管详情与 Sheet 层。
- `backend/app/schemas/source.py` 与 `backend/app/api/sources.py`：`SourceOut` 新增只读字段并复用既有批量任务查询；`backend/tests/test_sources.py`、`test_source_guards.py` 补用例。
- 不改 Web 前端；不改采集链路既有行为；不新增后端端点、不改数据库结构。
- Web 端来源列表存在同一缺口（不区分「有任务 / 无任务」），本 change 不处理，落地后与用户评估是否另开 change。

## Non-Goals

- 列表搜索、状态筛选、分页与独立「全部来源」页。
- 候选的确认 / 拒绝 / 写入 / 归档（仍回桌面 Web 或回对话讨论）。
- 展示 AI 建议（`recommended_project_id` / `project_recommendation_reason` 不渲染）。
- 待处理、知识栏目（继续显示真实未接入状态）。
- 录音、网页链接采集、系统分享入口、相机连拍。
- Web 前端改动与后端新端点。
