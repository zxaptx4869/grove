## MODIFIED Requirements

### Requirement: 项目侧栏项目切换下拉

项目上下文侧栏 MUST 在项目名旁提供项目切换下拉；下拉 MUST 列出全部非归档项目并按状态分组（进行中 / 暂停 / 已完成），当前项目 MUST 在其所属分组中置顶并显示选中态；选择其他项目 MUST 跳转到该项目并保留当前视图类型（项目首页 / 知识空间 / AI 阅读 / 确认台）；当前项目为已归档时 MUST 在下拉顶部单列显示以保留位置感；下拉 MUST 提供「全部项目」入口进入 `/projects`；非项目页面 MUST NOT 显示该下拉，保持「最近项目」区块。

项目状态 MUST 以「图标 + 语义色」展示：进行中使用圆点图标与成功色、暂停使用暂停图标与警告色、已完成使用对勾图标与确认色、已归档使用归档图标与弱化色；切换按钮 MUST 为单行布局（状态图标 + 项目名 + 箭头），与下方项目导航间距 MUST 不大于 8px；下拉项目项 MUST 显示状态图标，当前项目 MUST 在右侧显示选中勾。

#### Scenario: 状态图标化展示

- **WHEN** 用户进入项目工作台查看侧栏
- **THEN** 切换按钮单行显示「状态图标 + 项目名 + 箭头」，状态图标带可访问名称，不再单独显示状态文字

#### Scenario: 下拉项目项带状态图标

- **WHEN** 用户展开项目切换下拉
- **THEN** 每个项目项左侧显示对应状态图标，当前项目右侧显示选中勾，分组标题仍为文字

#### Scenario: 切换区域紧凑

- **WHEN** 用户查看项目工作台侧栏
- **THEN** 切换按钮与项目导航之间间距不大于 8px，无多余垂直留白

#### Scenario: 打开项目切换下拉

- **WHEN** 用户进入任意项目工作台并点击项目名旁的切换按钮
- **THEN** 下拉列出全部非归档项目，按「进行中 / 暂停 / 已完成」分组，当前项目在所属分组中置顶并显示选中态，底部提供「全部项目」入口

#### Scenario: 切换项目保留视图

- **WHEN** 用户在 A 项目的「知识空间」（或 AI 阅读 / 确认台）从下拉选择 B 项目
- **THEN** URL 切换到 B 项目并保持相同视图类型，页面与侧栏激活态同步

#### Scenario: 查看已归档项目

- **WHEN** 当前项目状态为已归档
- **THEN** 下拉顶部单列显示当前项目并标记选中态，其他已归档项目不进入列表

#### Scenario: 非项目页保持最近项目

- **WHEN** 用户在项目列表、收集箱或搜索页
- **THEN** 侧栏不显示项目切换下拉，仍显示「最近项目」区块
