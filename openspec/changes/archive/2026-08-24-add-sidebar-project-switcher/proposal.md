## Why

进入项目后，项目名在侧栏只是静态标题，切换项目必须先回到「项目」列表页再选择目标项目，项目工作台内没有直接切换入口，来回多一步，体验割裂。

## What Changes

- 项目侧栏的项目名旁新增下拉切换器：展开后列出全部非归档项目，按状态分组（进行中 / 暂停 / 已完成），当前项目置顶并显示选中态。
- 选择其他项目时保留当前视图类型（项目首页 / 知识空间 / AI 阅读 / 确认台），只替换 URL 中的项目 id 与对应路由段。
- 当前项目为已归档时，下拉顶部单列显示当前项目，避免「我在哪」丢失；其他已归档项目不进入列表。
- 下拉底部提供「全部项目」入口，进入项目列表页 `/projects`。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `product-shell`: 项目上下文侧栏新增项目切换下拉，支持全量非归档项目按状态分组选择，切换时保留当前视图类型。

## Impact

- 前端：仅修改 `frontend/src/components/layout/AppShell.tsx`（`ProjectNavigation` 项目名区域），复用现有 `useAllProjects` 与 `DropdownMenu` 组件；无后端、API、数据库变化。
- 测试：新增 AppShell 项目切换相关前端测试；`npm run lint`、`npm run test`、`npm run build`。
- 视觉验收：1280 / 1440 / 1600px 主视口检查侧栏相邻布局与下拉宽度、溢出。

## Non-Goals

- 不修改非项目页（项目列表 / 收集箱 / 搜索）的「最近项目」区块，两处入口并存。
- 不在下拉中提供项目搜索、创建、归档管理入口（项目多时再评估搜索）。
- 不调整侧栏宽度、品牌栏、顶栏结构；知识全景 / 思维导图沉浸式视图保持隐藏侧栏，不提供切换下拉。
- 不改变切换后的浏览器历史语义之外的行为（使用普通路由跳转）。
