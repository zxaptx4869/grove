## ADDED Requirements

### Requirement: 本地服务使用隔离快照和服务端身份
系统 MUST 提供仅绑定 loopback 的实验工作台服务。父进程 MUST 从 demo 原库创建一致副本，子进程 MUST 在导入应用数据库模块前绑定副本并关闭全部 Worker；服务端 MUST 使用钥匙串密码认证 demo 并固定用户、Workspace 和范围，MUST NOT 接受浏览器提交的身份、数据库路径或授权范围。原业务库 MUST 在运行前后保持不变。

#### Scenario: 启动本地工作台
- **WHEN** 用户启动实验工作台且 demo、钥匙串、模型配置、静态资源和隔离检查均通过
- **THEN** 服务只监听 `127.0.0.1`，显示实验版本、真实 Provider/模型、快照时间和就绪状态，启动本身不调用模型

#### Scenario: 隔离或真实模型前提失败
- **WHEN** 副本等于原库、Worker 未关闭、demo 认证失败、密钥不可用或模型会静默降级
- **THEN** 服务拒绝进入可提问状态并显示具体安全错误，不回退假模型、不写原库

### Requirement: 自由连续对话复用统一循环
工作台 MUST 直接复用 `dialogue-loop-v2` 的 Agent、结构化历史、只读工具、Evidence、输入门禁、单轮限制及收尾机制。用户 MUST 能自由输入任意问题、连续追问、切换话题和引用较早列表，不受固定评测题或四轮限制；服务批次文本与向量预算 MUST 跨对话共享，新建对话和刷新 MUST NOT 重置已消耗预算。

#### Scenario: 连续发送和列表追问
- **WHEN** 用户在同一对话发送任意问题，并继续引用之前显示的列表对象
- **THEN** 服务串行执行每轮并保留原型上下文、列表顺序和当前来源复验，不把评测预期或固定题目发送给 Agent

#### Scenario: 重复提交或同会话并发
- **WHEN** 同一会话已有活动轮次或客户端重复使用同一请求标识
- **THEN** 服务只接受一次并拒绝并发请求，不产生重复模型调用或串线

#### Scenario: 停止生成
- **WHEN** 用户停止当前活动轮次
- **THEN** 服务立即取消任务且不触发收尾模型请求，保留已核验可安全展示的材料并将轮次标为已取消

#### Scenario: 预算耗尽
- **WHEN** 共享批次或单轮预算无法继续派发
- **THEN** 页面显示实际限制和未完成状态，不自动重置预算、新建付费批次或把未执行表达为无结果

### Requirement: 刷新恢复与本地记录
工作台 MUST 在每次状态变化后将已完成消息、公开执行诊断和反馈写入 700/600 权限的本地记录。页面刷新 MUST 从服务端恢复当前会话；服务重启后 MUST 保留旧的已完成对话和反馈供只读查看，并明确说明其模型运行上下文不可继续恢复。

#### Scenario: 页面刷新
- **WHEN** 用户在已有已完成轮次的对话页面刷新
- **THEN** 相同对话、回答、执行记录和反馈重新显示，当前服务仍可恢复的对话保持可继续状态

#### Scenario: 服务重启后查看旧对话
- **WHEN** 新实验服务读取上一运行保存的记录
- **THEN** 旧对话以只读状态显示并明确提示运行上下文不可恢复，用户可查看和导出但必须新建对话才能继续提问

### Requirement: 回答和真实执行状态可审阅
工作台 MUST 展示文字、可信统计块、有序正式 Entry 列表和可展开来源。每轮 MUST 提供默认折叠的公开执行记录，包括实际工具、查询项目与筛选、状态、数量或有界摘要、当前来源、耗时、主 Agent 与内部工具模型调用数、估算、真实 usage、费用可得性、预算及收尾状态；MUST NOT 展示隐藏推理、密码、密钥或 Provider 隐藏元数据。

#### Scenario: 工具和来源成功
- **WHEN** Agent 使用统计、列表或 Evidence 工具形成回答
- **THEN** 页面按准确顺序渲染可信块，来源可展开查看已核验原文，折叠记录显示实际参数和状态

#### Scenario: 生成中的阶段
- **WHEN** 当前轮正在执行模型请求、知识查询、Entry 读取、来源核验或回答收尾
- **THEN** 页面仅显示后端实际发布的对应阶段，不伪造思考文本或未发生的进度

#### Scenario: 失败、材料不足或提前收尾
- **WHEN** 轮次失败、被取消、材料不足或进入独立收尾
- **THEN** 页面分别显示明确原因及已核验安全结果，估算与真实 usage 分开，缺少 token 或费用时显示未知

#### Scenario: Run 终态写入失败
- **WHEN** Agent 已形成回答、工具记录和模型 usage，但实验副本中的 Run 终态保存失败
- **THEN** 工作台仍将既有公开回答与诊断保存到本地记录，分别标明求解结果和 Run 保存失败，不把实际未知的调用数显示为零

#### Scenario: 隔离检查无法完成
- **WHEN** 轮次结束后的只读指纹查询抛出锁或其他异常
- **THEN** 工作台先保存轮次终态并停止后续数据库操作，明确显示“无法核验”而非断言业务数据已被修改；指纹等待不得阻塞异步事务释放

### Requirement: 反馈与脱敏导出
用户 MUST 能为每个助手轮次选择“答错了”“没理解”或“漏答”并填写说明。服务 MUST 将反馈关联本地会话、轮次、实验版本和诊断快照；用户 MUST 能下载同一份脱敏记录或看到明确本地路径。前端存储和导出 MUST NOT 包含密码、API key、隐藏推理或 HttpOnly 会话值。

#### Scenario: 保存和更新反馈
- **WHEN** 用户选择反馈类别并提交可选说明
- **THEN** 页面立即显示已保存状态，刷新后反馈仍关联原轮次且不会写入业务数据库

#### Scenario: 导出实验记录
- **WHEN** 用户点击导出
- **THEN** 服务下载包含实验元数据、对话、轮次、公开诊断和反馈的脱敏 JSON，并在页面显示服务器本地保存路径

### Requirement: 桌面实验工作台可访问且状态完整
工作台 MUST 使用现有 React、Tailwind、shadcn/ui 与 Lucide，遵循 Grove 语义令牌并从 1024px 开始提供三栏桌面流程；低于 1024px MUST 只显示电脑访问提示。加载、空、运行、完成、失败、取消、只读和禁用状态 MUST 保持布局稳定并可通过键盘操作。

#### Scenario: 桌面使用
- **WHEN** 用户在 1280、1440 或 1600px 宽桌面浏览器打开地址
- **THEN** 对话栏、聊天区和诊断栏无重叠或横向滚动，输入、停止、反馈、来源展开及执行记录可用

#### Scenario: 窄视口访问
- **WHEN** 浏览器宽度低于 1024px
- **THEN** 页面不加载实验业务工作台，只显示电脑端访问提示
