## Why

统一对话循环已经有固定评测报告，但报告不能替代真实自由提问体验。需要一个只在本机运行、直接复用现有原型和隔离边界的实验工作台，让用户亲自连续提问、查看可信结果与执行诊断，并把具体体验问题关联到可复查记录。

## What Changes

- 增加独立的本地实验服务和 React 桌面入口；启动时从 demo 数据创建一致隔离快照，在绑定副本数据库后才导入应用服务，并复用已有钥匙串、模型配置、Pydantic AI 统一循环及只读工具。
- 支持自由连续聊天、新建对话、停止生成、刷新恢复已完成记录，以及服务重启后明确只读展示旧记录；同一会话只允许一个活动轮次，预算不会因刷新或新建对话自动重置。
- 将回答渲染为文字、可信统计、有序 Entry 列表和可展开来源；每轮默认折叠展示真实工具条件、状态、摘要、来源、耗时、模型调用、估算、usage、收尾与预算，不展示隐藏推理。
- 增加“答错了／没理解／漏答”反馈及说明，按本地会话、轮次、实验版本和诊断关联保存；支持下载脱敏 JSON，并公开本机保存路径。
- 使用 HttpOnly 本机会话绑定服务端已验证的 demo 用户与 Workspace；浏览器不能提交或覆盖身份、数据库路径和授权范围。服务只监听 loopback，不注册到正式 App/API/Worker。
- 增加离线模型/桩的后端和前端自动化，以及桌面浏览器的多视口、刷新、取消、失败、预算耗尽、来源展开、反馈和导出验证；自动化不触发真实模型。

非目标：不修复既有回答语义质量、不增加规划器、分类器、覆盖检查模型或写知识能力；不接入正式 Grove 导航、Agent API、Worker 或客户端；不把本地实验服务视为生产部署方案。

## Capabilities

### New Capabilities

- `knowledge-agent-experiment-workbench`：本地隔离的自由对话实验服务、桌面工作台、执行可观测性、反馈与脱敏导出。

### Modified Capabilities

无。正式产品的 Knowledge Agent 路由、数据合同和运行生命周期不在本 change 中改变。

## Impact

- 新增 `backend/evals/dialogue_workbench/`，复用 `backend/evals/dialogue_loop/` 和现有应用只读服务；新增对应后端测试、本地启动/停止脚本及忽略的数据目录。
- 新增独立 Vite 多页入口及 `frontend/src/experiments/dialogue-workbench/`，复用现有 Tailwind 语义令牌、shadcn/ui 与 Lucide；不加入正式 App 路由和导航。
- 不新增数据库迁移、正式端点或生产配置。隔离数据库只在实验进程生命周期内使用；已完成对话、反馈和脱敏诊断写入本地 700/600 权限目录。
