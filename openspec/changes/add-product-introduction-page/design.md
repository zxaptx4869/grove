## Context

范围与行为见 proposal 和增量规格。用户授权直接实施正式页面，无独立原型。现有 AuthLayout 是 52px 品牌栏与 360px 表单，全局 DesktopBoundary 阻断小屏所有路由。

## Goals / Non-Goals

以两个场景、三个 AI 能力与三个端解释产品，桌面首屏保留登录。只展示产品能力，不增加业务能力、模拟登录或商店链接。

## Decisions

- 在正式 LoginPage 中组合公开 ProductIntroduction 与原有登录表单；登录表单独立为 LoginForm，保持接口、错误与跳转语义。
- 登录页使用独立公共布局，注册页继续使用 AuthLayout，避免介绍干扰注册流程。
- DesktopBoundary 仅对 `/login` 放行；小屏 `/` 引导介绍，其余路由维持阻断。公开页没有业务查询；通过统一视口 hook 保证小屏不挂载 LoginForm。
- 说明性流程采用原生 HTML 和 Lucide，明确标注示例，无静态业务 API 或伪造操作。以目录树、候选与对话的可读结构直接展示产品价值。
- 不更改全局主题，新增页面局部样式；公共展示标题有意大于工作台字号，因用户明确要求产品介绍，原工作台的非营销式布局不约束公共介绍。

## 视觉基线

| 层级 | 基线 |
|---|---|
| 主题 | 复用 index.css：背景 #f7f8f7、白色表面、品牌 #236748、正文 #17201c、次文字 #66716b、边框 #dde3df、AI #7251a5 |
| 字体 | 复用系统中文字体；介绍主标题桌面 52px/1.2，移动 34px/1.25；正文 15px/1.8；区块标题 32px；表单标题 22px/650 |
| 页面 | 品牌栏 72px，最大宽度 1200px，桌面水平留白 40px、移动 20px；首屏介绍与登录两列；内容区块间距 88px |
| 表单 | 360px 内容宽、36px 控件，复用既有错误和提交禁用状态；小屏用电脑登录提示替代 |
| 示意 | AI 草稿与正式状态使用语义色和文字；静态示例不做操作按钮；大段文字自动换行 |
| 视口 | 1440px 主视口，1280/1600 扩展，1023/1024 边界，390px 公共介绍 |

## Risks / Trade-offs

- 示例可能被误认成已加载用户数据 → 每个示意区域标明示例，使用虚构说明材料。
- 小屏公开入口可能放开业务 → 路径精确匹配、路由测试验证没有业务查询及认证表单。

相关前端测试、lint、build 和 OpenSpec 全库严格校验；浏览器截图及计算样式覆盖上述矩阵、锚点、键盘与错误状态。证据放 artifacts/product-introduction/，仅本地保存。页面效果由用户审阅，归档按 AGENTS.md 取得针对同步差异的批准后执行。
