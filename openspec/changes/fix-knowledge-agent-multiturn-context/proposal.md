## Why

真实多轮基线显示，当前范围未进入上下文理解，统计与澄清后的主题承接中断，依据限制规则还会把通用知识请求反向解释。结果是 48 次实际提问只有 3 次通过确定性检查；项目统计另有范围缺失与工具维度不足。详见 `docs/验收记录/knowledge-agent-multiturn-baseline-2026-09-05.md`。

## What Changes

- 将当前可信范围、有限对话主题、待澄清任务及最近展示对象提供给上下文决策；对话意图承接不以事实工作集为前提，仍隔离范围切换、新话题与失败数据。
- 统计追问继承必要集合条件、支持用户替换条件；列表序号引用只解析服务端实际展示对象，并在本轮重新校验和读取。
- 明确全部知识默认包含全部正式 Entry 类型；修复通用知识与个人知识库限制混淆，失败回退保留用户依据限制。
- 为受限集合增加项目名称筛选，由服务端在 Run 授权范围内精确解析；增加按项目分组、零条项目和项目名称展示，不允许模型指定授权 id 或改变 Run 范围。
- 复用并增强现有真实多轮评测，补充范围、恢复、未写入及调用方兼容验证。

不实现通用 B2 Agent 循环、外部搜索、知识写入或 Operation Plan。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `knowledge-agent-follow-up`：可信范围、独立于事实工作集的对话承接、澄清恢复与结果对象指代。
- `knowledge-agent-structured-query-tools`：项目名称子集、项目分组和全部知识类型口径。
- `knowledge-agent-answer-basis`：通用知识限制的正确识别与跨回退路径保持。

## Impact

后端上下文决策、依据策略、结构化/复合查询与执行、Run 诊断和结果 schema；原生端分组展示与 API 类型兼容；多轮评测及必要自动化测试。优先复用已持久化 Run、消息和快照表达对话状态，不新增正式知识对象。新能力通过可选字段保持旧 Run 可读；项目 id、Workspace 和对象读取权限继续由服务端控制。
