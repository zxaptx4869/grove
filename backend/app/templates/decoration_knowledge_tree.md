# 房子装修

- 项目目标：未填写

## 知识目录

- 装修准备 — 装修前的规划与准备工作
  - 需求确认 — 明确装修需求与目标
    - 户型分析 — 分析115平户型特点与改造潜力
    - 风格定位 — 确定现代简约风格的具体方向
    - 预算框架 — 制定总预算及分配比例
  - 资料收集 — 收集装修相关参考资料
    - 案例参考 — 收集现代简约风格装修案例
    - 材料信息 — 收集环保材料品牌与价格信息
      - 基本信息 — 包含材料名称、编号、规格、生产厂家等基础属性
      - 成分与配方 — 材料的化学成分、配比、添加剂等组成信息
      - 性能参数 — 力学、热学、电学、光学等性能指标
      - 加工工艺 — 成型、热处理、表面处理等加工方法
      - 应用领域 — 材料适用的产品、行业或场景
      - 质量标准与认证 — 相关标准、认证及合规性信息
      - 供应商信息 — 供应商联系方式、资质、供货情况等
      - 检测与试验报告 — 检测数据、试验结果及分析
      - 安全与环保信息 — MSDS、环保合规、储存要求等
    - 施工知识 — 了解施工工艺与验收标准
- 设计规划 — 空间布局与设计方案
  - 空间布局 — 优化空间利用与动线设计
    - 功能分区 — 合理划分客餐厅、卧室、厨卫等功能区
    - 收纳设计 — 规划全屋收纳系统，提升空间利用率
    - 动线优化 — 优化日常活动动线，提高生活便利性
  - 风格设计 — 现代简约风格的具体设计
    - 色彩搭配 — 确定主色调与点缀色，营造简约氛围
    - 材质选择 — 选择符合环保与简约要求的材质
    - 灯光设计 — 设计主照明与辅助照明，营造层次感
  - 图纸管理 — 设计图纸的确认与存档
    - 图纸确认 — 审核工作室提供的设计图纸
    - 图纸存档 — 保存施工图纸供施工与验收参考
- 施工阶段 — 装修施工过程管理
  - 拆改工程 — 墙体拆改与结构改造
    - 拆墙砌墙 — 按图纸进行墙体拆改
    - 垃圾清运 — 及时清运建筑垃圾
      - 除渣类型 — 按渣的性质分类，决定收费方式
        - 硬渣 — 拆墙、砖头等建筑类渣，按车收费
        - 软渣 — 除硬渣外的其他垃圾，按桶收费
      - 收费方式 — 不同渣类型的计费规则
        - 硬渣按车计费 — 按车收费，看车的体积（方数）
        - 软渣按桶计费 — 按桶收费
      - 服务商选择 — 选择除渣服务商的考量因素
        - 比价 — 记录各家价格，方便对比
        - 响应速度 — 服务商接单和上门的速度
        - 处理质量 — 除渣处理是否干净、到位
        - 联系方式 — 记录服务商联系人、电话等信息
  - 水电工程 — 水电改造与隐蔽工程
    - 电路改造 — 布线、插座开关安装
    - 水路改造 — 水管铺设与防水处理
    - 验收测试 — 进行水电打压与电路测试
  - 泥瓦工程 — 瓷砖铺贴与防水施工
    - 防水施工 — 厨卫防水处理与闭水试验
    - 瓷砖铺贴 — 墙地砖铺贴与美缝
  - 木工工程 — 吊顶与定制柜体安装
    - 吊顶安装 — 客厅、厨卫吊顶施工
    - 柜体定制 — 定制衣柜、橱柜等安装
  - 油漆工程 — 墙面与木器涂装
    - 墙面处理 — 刮腻子、刷乳胶漆
    - 木器漆 — 木制品刷漆或喷漆
  - 安装工程 — 主材与设备安装
    - 厨卫安装 — 洁具、橱柜、烟机灶具安装
    - 灯具开关 — 灯具与开关插座安装
    - 门与地板 — 室内门与地板安装
- 质量控制 — 施工质量与环保把控
  - 材料验收 — 进场材料验收与环保检测
    - 主材验收 — 瓷砖、地板、板材等主材验收
    - 辅材验收 — 水泥、砂浆、胶水等辅材验收
    - 环保检测 — 检测甲醛等有害物质含量
  - 施工监督 — 施工过程监督与检查
    - 节点验收 — 水电、泥瓦、木工等关键节点验收
    - 问题整改 — 发现质量问题及时整改
    - 进度管理 — 跟踪施工进度，确保按期完成
  - 竣工验收 — 整体验收与交付
    - 细节检查 — 检查收口、平整度、缝隙等细节
    - 功能测试 — 测试水电、门窗、厨卫等功能
    - 整改复验 — 整改后复验，确保合格
- 预算与采购 — 预算控制与材料采购
  - 预算管理 — 控制总预算与各项支出
    - 预算分配 — 按项目分配预算比例
    - 费用记录 — 记录每笔支出，对比预算
    - 超支控制 — 分析超支原因并调整
  - 材料采购 — 选购装修材料与家具
    - 主材采购 — 瓷砖、地板、橱柜、洁具等
    - 辅材采购 — 水泥、电线、水管等
    - 家具家电 — 沙发、床、冰箱、洗衣机等
  - 供应商管理 — 管理材料供应商与售后
    - 比价议价 — 对比价格，争取优惠
    - 合同与发票 — 签订合同并索要发票
    - 售后保障 — 确认保修期与售后服务
- 软装搭配 — 家具与装饰品搭配
  - 家具选购 — 选择现代简约风格家具
    - 客厅家具 — 沙发、茶几、电视柜等
      - 沙发 — 客厅中用于坐卧的主要家具，包括单人沙发、双人沙发、三人沙发及组合沙发等。
        - 布艺沙发 — 以布料为主要面料的沙发，触感舒适，风格多样，易于清洁。
        - 皮质沙发 — 以真皮或人造革为面料的沙发，质感高档，耐用易打理。
        - 功能沙发 — 具备电动或手动调节功能，如可躺、可摇、可旋转等，提升舒适度。
      - 边几 — 放置在沙发旁或角落的小型桌子，用于摆放台灯、茶杯等物品。
        - 角几 — 放置在客厅角落的边几，充分利用空间，增加收纳。
        - 沙发边几 — 紧邻沙发摆放的边几，方便取用物品，提升便利性。
      - 休闲椅 — 供单人坐卧的椅子，常用于阅读、休息或会客，款式多样。
        - 躺椅 — 可调节靠背角度，适合放松休息。
        - 摇椅 — 底部有弧形摇杆，可前后摇动，增添休闲趣味。
        - 懒人沙发 — 柔软可变形，随意坐卧，营造舒适慵懒氛围。
      - 地毯 — 铺设于客厅地面的织物，起到装饰、隔音、保暖作用。
        - 羊毛地毯 — 天然羊毛材质，柔软保暖，质感高级。
        - 化纤地毯 — 合成纤维材质，耐磨易清洁，价格实惠。
        - 混纺地毯 — 多种纤维混纺，兼顾舒适性与耐用性。
      - 灯具 — 客厅中提供照明和营造氛围的灯具，包括主灯、落地灯、台灯等。
        - 吊灯 — 悬挂于天花板中央的主照明灯具，造型多样。
        - 吸顶灯 — 紧贴天花板安装的灯具，简洁实用。
        - 落地灯 — 放置于地面的可移动灯具，提供局部照明。
        - 台灯 — 放置于茶几或边几上的小型灯具，用于阅读或氛围照明。
      - 窗帘 — 用于遮挡光线、保护隐私的布艺，兼具装饰功能。
        - 布艺窗帘 — 以布料为主，遮光性好，款式多样。
        - 百叶窗 — 由叶片组成的窗帘，可调节光线，简约现代。
        - 纱帘 — 轻薄透光，营造柔和光线，常用于内层。
      - 抱枕 — 放置在沙发或椅子上的软垫，增加舒适度与装饰性。
        - 方形抱枕 — 常见方形，尺寸多样，图案丰富。
        - 圆形抱枕 — 圆形设计，造型可爱，增添趣味。
        - 腰枕 — 长条形，用于支撑腰部，提升坐姿舒适度。
      - 绿植 — 客厅中摆放的盆栽植物，净化空气，增添生机。
        - 大型绿植 — 如琴叶榕、龟背竹等，适合摆放在角落或沙发旁。
        - 小型盆栽 — 如多肉、绿萝等，适合摆放在茶几、边几或装饰柜上。
      - 装饰品 — 用于点缀客厅空间、提升艺术氛围的装饰物件，涵盖墙面挂饰与台面摆件。
        - 挂画 — 装裱好的画作，风格多样，如抽象、风景、人物等。
        - 照片墙 — 由多幅照片或图片组合而成的墙面装饰。
        - 摆件 — 摆放在台面或地面上的立体小装饰，如花瓶、雕塑、相框等。
    - 卧室家具 — 床、衣柜、床头柜等
    - 餐厅家具 — 餐桌椅、餐边柜等
  - 窗帘布艺 — 窗帘、地毯与抱枕搭配
    - 窗帘选择 — 根据风格选择窗帘材质与颜色
    - 地毯搭配 — 选择合适的地毯增添温馨感
    - 抱枕装饰 — 通过抱枕点缀色彩
  - 装饰品 — 挂画、绿植与摆件
    - 挂画 — 选择简约风格装饰画
    - 绿植 — 摆放绿植净化空气与美化空间
    - 摆件 — 挑选精致摆件提升格调
- 入住准备 — 装修后入住前准备
  - 通风除味 — 通风散味与空气净化
    - 通风时间 — 保持通风至少1-3个月
    - 活性炭/绿植 — 放置活性炭与绿植吸附甲醛
    - 空气检测 — 检测空气质量达标后再入住
  - 清洁开荒 — 全面清洁与开荒保洁
    - 全屋清洁 — 清洁墙面、地面、玻璃等
    - 家具清洁 — 清洁家具表面与内部
    - 垃圾处理 — 处理装修垃圾与废弃物
  - 搬家入住 — 搬家与入住安排
    - 物品打包 — 分类打包物品并标记
    - 搬运安排 — 联系搬家公司或自行搬运
    - 入住检查 — 检查水电燃气等设施正常
