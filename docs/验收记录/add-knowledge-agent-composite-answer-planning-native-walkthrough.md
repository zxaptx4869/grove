## 职责边界

AI 已完成原生端自动化测试、类型检查与 lint 后提供本清单；默认不启动或操作模拟器、

## 走查清单

1. 在“回答依据 = 自动”“回答方式 = 快速”下提问：
   “甲醛是什么？结合我的知识说明来源和环保等级。”确认回答先解释概念，再使用真实
   Grove 知识回答后两项；缺少其中一项时应明确显示缺口，不得直接遗漏。
2. 提问一个与知识库无关的通用问题，确认可给出模型通用回答，依据展示不伪造 Grove
   Citation。
3. 选择“只依据知识库”后提问纯知识库问题，确认没有合法 Evidence 时显示知识不足，
   不用模型常识补齐。
4. 提问“解释环保等级，并统计相关知识总数”，确认解释和统计同时出现；只有完整纯结构化
   集合才使用精确计数措辞。
5. 提问带语义条件的统计问题，确认 top-k 或预算截断结果显示 limited/unknown，不显示为
   当前范围的精确全集。
6. 构造一项有结果、一项缺少依据的问题，确认整体显示 partial，已完成内容仍保留，缺口
   可见。
7. 在模型不可用或切换到未配置模型的测试环境中提问，确认 fallback 可识别，不静默展示
   为真实模型成功。
8. 在回答执行中退出页面或重启 App，再回到原对话，确认从服务端恢复原 Run；已完成结果
   不重复、历史回答和逐项状态一致。
