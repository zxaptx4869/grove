# 目录与知识空间

[返回产品蓝图索引](../产品蓝图.md)

> 权威范围：目录共创、知识浏览、卡片与列表、思维导图、搜索、AI 阅读与页面信息架构。

## 目录共创

### 产品定位

新项目默认允许空目录，提供两个平等入口：

```text
手动创建第一个节点
与 AI 共创目录
```

目录共创应由独立的 Directory Agent 承担，而不是一次无状态的“生成目录”调用。

### 三类任务

1. 从零起草：根据项目说明和必要澄清生成候选目录。
2. 节点拓展：读取目标节点、现有子树、项目上下文与相关 Entry，提出更细结构。
3. 调整现有目录：根据自然语言提出新增、改名、移动、更新说明和建议删除。

节点拓展入口位于知识空间目录树的节点菜单与选中节点的内容区；AI 输出目标节点下的完整目标子树（含应保留的现有子节点），系统按名称递归计算“新增 / 保留 / 建议移除”差异供用户逐项确认。目标节点自身与保留节点不被 AI 修改；真正的改名、移动与改说明属于“调整现有目录”能力。

### 统一工作流

```text
用户目标或对话
      ↓
Directory Agent
      ↓
可视化目录草稿
      ↓
结构差异：新增 / 改名 / 移动 / 建议删除
      ↓
用户确认
      ↓
正式目录
```

首次从零起草可返回完整候选树；后续调整优先返回结构化操作，避免完整重写导致节点漂移或丢失。

建议操作类型：AddNode、RenameNode、MoveNode、UpdateDescription、SuggestRemoveNode。

节点拓展与后续目录调整中的“建议移除”默认勾选（经旧项目实测确认，默认不选中会让用户误以为 AI 未响应），但子树含正式 Entry 的节点受保护、不可勾选，并显示阻断数量；差异面板同时展示受影响的子节点与 Entry 数量。正式变更由应用层校验并原子执行。

## 知识使用方式

### 目录浏览

项目知识的主要入口。用户通过目录理解结构，并查看当前节点直接挂载的 Entry 或包含子树的 Entry。

### 卡片与列表

同一批 Entry 的两种视图，不是两种数据模型：

- 卡片：适合阅读、回顾和探索，突出核心内容、适用条件、类型和来源。
- 列表：适合扫描、筛选、排序和批量管理，突出标题、目录、类型、来源和更新时间。
- 系统记住项目内视图偏好。

### 知识全景与思维导图浏览

知识全景是项目级沉浸式阅读视图（唯一入口，与知识空间目录浏览、AI 阅读平级），包含「旭日图 | 思维导图」两种模式，默认展示旭日图；顶部切换，支持跨模式联动，不是编辑器。

**旭日图模式（全局认知）**

- 扇区按深度单色着色，扇区宽度 = 知识量；计数沿用「直接 / 后代 / 合计」口径，与目录浏览的「仅后代」区分；
- hover 高亮祖先路径并显示「直接 / 后代 / 合计」；点击扇区图内钻取，面包屑返回；
- 标签按弧长缩写、hover 补名；
- 支持缩放与平移（滚轮以光标为中心、按钮、适应窗口），不依赖第三方库；
- 右侧目录大纲点击联动旭日图；直接知识列表配合悬浮详情（hover 预览、点击固定）。

**思维导图模式（空间回忆）**

- 图中默认只展示目录节点，不铺开全部 Entry；节点徽标为「直接数 / 合计数」；
- 点击节点就地展开直接知识：叶子节点在右侧居中堆叠、非叶子节点在下方堆叠，再点收起；
- 知识小卡与侧栏条目 hover 预览、点击固定悬浮详情；侧栏可勾选「包含子树」（默认勾选）浏览节点范围知识；
- 支持展开、收起、聚焦子树和搜索高亮；画布线格背景固定，不随内容滚动；
- 无壳沉浸，画布占满窗口；目录编辑、移动、删除和 AI 拓展仍在标准目录管理界面完成，通过「在知识空间中打开」跳转定位。

### 搜索

- P0：项目内和全局关键词搜索，覆盖标题、内容、目录和来源摘要。
- 后续：组合筛选、语义搜索、相似知识和搜索结果问答。
- 全局搜索可以跨项目找到 Entry，但不改变 Entry 的项目归属。

### AI 阅读与提问

第一版定位为“带证据的知识阅读器”，不是依靠模型常识自由回答的聊天机器人。

支持范围：

- 节点阅读：当前节点及其子树；
- 项目阅读：整个项目。

规则：

1. 默认只读取已确认 Entry。
2. 关键结论附 Entry 与 Source 引用。
3. 显示冲突、适用条件和知识不足。
4. 知识库不足时明确说明，不用模型自身知识悄悄补齐。
5. 即时回答不是正式知识；保存回答内容时必须转为 Candidate 再确认。
6. 外部知识模式后置，并明确区分“仅我的知识库”和“知识库 + 外部发现”。

## 信息架构与关键页面

### 全局层

```text
项目
收集箱
搜索
账户
```

- 项目：项目列表、状态筛选和创建入口。
- 收集箱：全局采集、未归属 Source、处理状态和待确认入口。
- 搜索：跨项目查找已确认 Entry。
- 账户：个人设置、AI Provider 与数据管理，后续逐步补齐。

### 项目层

```text
项目首页
知识空间
确认台
采集与来源
AI 阅读
```

- 项目首页：下一步任务、最近知识、处理进度和项目理解，不做装饰性数据看板。
- 知识空间：目录、卡片、列表和知识全景（旭日图 + 思维导图）。
- 确认台：按采集审阅与批量处理。
- 采集与来源：项目内采集、Source 列表、处理状态、失败重试和来源详情。
- AI 阅读：节点或项目范围的带引用问答。

### 端侧职责

页面信息架构按桌面工作效率设计，不维护手机 Web 简化版。支持宽度、小屏阻断页与原生 App 的完整边界统一由[技术与端侧边界](技术与端侧边界.md#端侧产品边界)维护。
